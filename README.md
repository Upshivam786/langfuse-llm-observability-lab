# Langfuse LLM Observability Lab

A hands-on project exploring LLM observability, tracing, prompt management,
evaluation, and Retrieval-Augmented Generation (RAG) diagnostics using Langfuse.

## Experiments

### 01 - Basic LLM
- LLM tracing and error tracking
- Metadata and execution context
- Prompt management and versioning
- Evaluation and scoring

### 02 - RAG
- Basic RAG pipeline
- RAG evaluation
- Retrieval diagnostics

## Tech Stack
- Python
- Langfuse
- Large Language Models (LLMs)
- Retrieval-Augmented Generation (RAG)
